# Simple-CI-CD-WebApp

Este proyecto consiste en una **Aplicación Web básica** desplegada usando **Flask**, un micro-framework para Python, con **CI/CD** (Integración Continua y Despliegue Continuo) implementado a través de Render. El objetivo del proyecto es demostrar un flujo simple desde el desarrollo local hasta el despliegue en la nube usando un pipeline de CI/CD.

## Tecnologías usadas:
- *Python 3.12*
- *Flask* para crear el backend
- **Render** para el despliegue automatizado
- **GitHub Actions** para el proceso de CI/CD
- **Python-dotenv** para gestionar variables de entorno de manera segura

## Pasos realizados:
1. *Instalación local:* Configuración del entorno de desarrollo virtual y creación de la app Flask.
2. *Uso de GitHub:* Inicialización del repositorio, creación de un flujo de trabajo para CI/CD y configuración de los archivos relevantes.
3. **Despliegue en Render:** Conexión del repositorio de GitHub con Render para desplegar automáticamente la app en la nube.
